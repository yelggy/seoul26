# Korea 26

Night-route trip journal for Carlo, Cyrill, Simon & Adrian — **5–17 October 2026**.

**Live:** [https://yelggy.github.io/seoul26/](https://yelggy.github.io/seoul26/)

## Files

- `index.html` — journal UI + inline editor script
- `assets/styles.css` — dark charcoal / warm paper theme
- `places.json` — verified seed route
- `.nojekyll` — serve as static files on GitHub Pages

## Editing

Open the page, tap **Edit · Bearbeiten**. Add, edit, reorder, delete, and mark stops done. Changes persist in `localStorage`. Use **Reset to seed** to restore `places.json`, or **Download JSON** to export the current list.
